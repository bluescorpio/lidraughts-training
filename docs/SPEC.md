## §5.2 领先锁住训练

正式三步训练仍在「锁住清单」页（与答题计数 `leadLock` 相关的流程保持分离）。

### 5.2.1 全局浮动「锁住清单」卡片（随时唤起）

**目的**：训练页之外，慢棋/实战中也可一键唤起，把「领先后换下法」做成可见提醒，而不必进入完整答题流程。

**UI 要求**：

- 全局固定入口：右上角或浮动菜单按钮，文案 `🛡️ 锁住清单`（儿童端与家长端均可见）。
- 点击后弹出轻量模态/底部卡片，**仅三行醒目大字**（可勾选，勾选状态本会话保留即可）：
  1. **查反击**：对手现在唯一能反击的线/子在哪里？先把它封死或兑掉！
  2. **做简化**：能不能用最安全的 1 换 1 把局面缩小？能就换！
  3. **停设饵**：现在优势在手，坚决不送饵、不打风险组合！
- 不强制棋盘作答；不计入 `leadLock.attempts`（与正式训练题分离）。
- 可选：卡片底部链到「进入锁住训练题」（跳转锁住清单页）。
- 文案禁止焦虑营销；保持指令句、短句。

**完成标准：** 任意模块页面均可唤起；三行文案与上表一字不差（可微调标点，不可改语义）；关闭后再开状态符合「本会话保留勾选」约定。

## §5.6 四指标复盘速记器（MVP 薄版）

MVP **必须实现**薄版速记器；完整周报 / 与 R1–R9 基线叠图可留 V2，但数据结构一次到位。

### 5.6.1 四指标复盘速记器

**入口**：家长看板内「对局速记」；可选全局入口「📝 复盘速记」。目标操作时长 ≤ 30 秒。

**表单字段（固定选项，禁止自由长文本为主）**：

| 字段 key | 问题文案 | 选项（存枚举值） |
| --- | --- | --- |
| `counterAfterCombo` | 组合结束后是否被反打？ | `0` 完美 / `1` / `2plus`（2 次以上） |
| `leadHeld` | 领先优势是否守住？ | `held_win` 守住转化为胜 / `blown` 优势被反噬 / `na` 本局不明显领先 |
| `kingFirstSafe` | 升王第一步是否安全？ | `yes` / `no` / `no_king` 本局无王 |
| `planScore` | 均势无战术时是否有计划？ | `1` / `2` / `3` |
| `date` | 日期 | ISO 日期，默认今天 |
| `source` | 来源 | `lidraughts` / `otb` / `other`（默认 lidraughts） |
| `note` | 一句话（可选） | ≤ 30 字 |

**持久化**：写入 localStorage `wz-counter-trainer-v1` 下数组 `metricLogs[]`；每条含 `id`、`createdAt` 与上表字段。

**展示（MVP 最低）**：

- 列表：最近 20 条；
- 折线/趋势：至少 `counterAfterCombo`（映射 0/1/2）与 `planScore` 两条近 8～12 盘趋势；`leadHeld` / `kingFirstSafe` 可用占比小卡。
- 不要求自动周报（V2）；但导出 JSON 必须包含 `metricLogs`。

**与训练红线**：速记器是家长/教练向；儿童端可不展示趋势，只保留可选「帮爸爸勾一下」入口（若做，仍用大按钮三步内完成）。

**完成标准：** 提交一条记录刷新不丢；导出/导入后仍在；四题选项与上表一致。

## §5.9 经典打击教材 · 21 种武器库（打卡 + 红星错题）

对应训练方案「动作五：维持经典战术打击库」与教练「红星盲区题」说法。与战术专项导入关卡的关系：导入关卡管谱系标签/收藏；**本节专指手头 21 章教材的进度与红星复习**，数据分离、入口可互链。

### 5.9.1 目标

把「21 种经典打击」做成可打卡的武器库：日常轻量保持进攻嗅觉；把卡顿题标红星，汇入专属复习页，供每周集中消灭盲区。

### 5.9.2 信息架构

- 导航：可在顶部增加 `⚔️ 打击武器库`；**儿童端需有大按钮入口**。
- 两页：① 21 章进度列表 ② 红星复习页。

### 5.9.3 章节数据

内置常量 `WEAPON_CHAPTERS`（21 项）。展示名允许产品微调，**数量固定 21**，id 稳定为 `w01`…`w21`。默认中文名（可按实际教材目录替换，替换时只改 title，不改 id）：

6. w06 交叉打击
7. w07 双击与抽子
8. w08 底线架桥
9. w09 偷袭升王
10. w10 后根 / 桩子打击（Butoir）
11. w11 拿破仑打击（Napoléon）
12. w12 开口打击
13. w13 中路突破

若家长提供教材真实目录，用真实章名覆盖 title；**不得删减章节数**。

每章进度状态：`locked` | `in_progress` | `done`（MVP 可手动点选「本节打卡完成」，不强制棋盘题）。

### 5.9.4 红星错题

- 任意教材练习情境（站内题或「外部题打卡」）提供按钮 `⭐ 标为红星`。
- **自动建议标星规则（可选助手）**：若站内计时题作答耗时 > 10 秒，提示「要标红星吗？」；用户确认后写入。当前站内尚无计时题，MVP 仅手动标星。
- 红星记录字段：`{ id, chapterId, title?, markedAt, source: "in_app"|"external", cleared: bool }`。
- **红星复习页**：只列出 `cleared != true` 的红星；支持「本周复习打勾」→ `cleared=true`（可恢复）。
- 与反打错题本：可双向链接，但存储集合分离（`weaponStars[]` vs 反打 `mistakeBook` / `misses`），避免混统计。

### 5.9.5 统计（进入家长看板）

- `weapons.chaptersDone` / `weapons.starsOpen` / `weapons.starsClearedThisWeek`
- 不设全国排名或与他人比较。

### 5.9.6 非目标（本模块不做）

- 不把 21 章扩成海量自动生成题库；
- 不强制每天刷完一章；默认每周轻量（与「不题海」一致）；
- 不引入付费教材版权文本全文（仅章名/进度/用户自建题目标记）。

**完成标准：** 21 章可打卡且刷新保持；红星可标记/汇聚/清除；看板数字正确；导出 JSON 含 `weaponProgress` 与 `weaponStars`。
