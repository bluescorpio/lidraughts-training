# 产品规则（王植训练站）

国际跳棋（100 格）家庭训练站：给孩子 Zack / 王植用的「少而准」练习，不是题海 App。

## 角色与页面

| 角色 | 可见页面 |
| --- | --- |
| **孩子** | 今天、题库、锁住清单、复盘本、周计划 |
| **家长** | 以上全部 + **资料库**（建局、PDN、标记、生成出题草稿、发布今日题） |

页眉切换「孩子 / 家长」。数据仅存本机 `localStorage`（`wangzhi-train-v1`），无账号。

## 「今天」

- 每天最多 **1** 道已发布题。
- 无任务时显示「今天没有任务」（或等价温和文案），不催促加题。
- 完成：自检「我对了 / 有点漏了」+ 可选点格标记。

## 复盘四指标

每盘慢棋/比赛只记这四项（见训练方案）：

1. **组合后被反打丢子次数** → 目标压到 0
2. **子力最高峰与终局差值** → 全盘保持非负
3. **升王首步是否在安全位** → 目标 100%
4. **无战术阶段计划性评分（1–3）** → 目标 ≥ 2.5

## 红线

- 不题海、不比较、不焦虑文案。
- 不扩开局谱（白 32-28、黑 18-23 保持即可）。
- 提示语温和、可执行（先封反击、再简化、停设饵）。

## Zack 上下文（给 agent）

- 天津青少赛约全国第 5；执白稳、执黑负于冠亚军。
- 长处：战术嗅觉、设饵连吃、抗压恢复。
- 主短板：组合终点反打盲区、领先后不锁住、无战术时缺计划、深推无援。
- 训练主线：反打预警题库 + 锁住清单 + 限制性慢棋；详见 `docs/reference/`。
